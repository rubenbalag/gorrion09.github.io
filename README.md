# Portfolio de Rubén Balaguer Picó

Web personal en HTML, CSS y JavaScript: https://rubenbalag.github.io/gorrion09.github.io/.

No necesita instalación ni compilación. Servir la raíz con cualquier servidor HTTP estático. Las rutas relativas son compatibles con GitHub Pages en un subdirectorio.

Para actualizar el CV, sustituir `public/docs/CV_Ruben_Balaguer_Pico.pdf` conservando el nombre.

La versión actual usa `index.html`, `style.css` y `main.js`. Se conserva `script.js` de la versión anterior, sin cargarlo en la página.
